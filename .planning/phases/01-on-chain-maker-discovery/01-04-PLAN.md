## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `deployer` identity → Testnet | The deploy and `initialize` transactions establish the admin; whoever initializes first owns the instance |
| `public/otc-config.js` → the browser | An un-bundled `window.*` script the browser executes; a wrong or hostile id here is what every future consumer would call |
| `tools/rfq-registry-live.mjs` → Testnet + Friendbot | Creates and funds throwaway keypairs and signs real transactions |
| deployed contract → Phase 2 desk | The id published here is what Phase 2 builds discovery on |
