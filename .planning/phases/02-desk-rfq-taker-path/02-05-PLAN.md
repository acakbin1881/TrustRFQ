<objective>
Make the whole RFQ taker path runnable as one command and prove the phase's security posture did
not move. The stub maker registers itself on the real Testnet registry, the desk discovers it
through the ordinary read path, the flow settles for real, the stub ejects with a full refund, and
the content-security-policy allow-list is byte-for-byte what it was before this phase started.

Purpose: E2E-01 is the intermediate verification that lets Phase 3 be a swap of the counterparty
rather than a rewrite of the taker. If the harness needs any test-only code under `src/`, the thing
being verified is not the thing that will ship. And CSP-01 is a posture check with a deliberately
empty result this phase: no real maker origins exist yet, and the local stub is invisible to the
deployed headers, so the correct change is no change.

Output: the census entry point, the CSP audit, the phase-wide artifact record, and one human
verification of the panel against its design contract.
</objective>

| Boundary | Description |
|----------|-------------|
| local stub maker -> browser | A loopback HTTP origin the desk fetches during the census; invisible to the deployed policy because the preview server sets no headers |
| deployed edge policy -> browser | The audited allow-list that governs the real site; widening it is the security-relevant act, not fetching from a developer machine |
| E2E run -> live Testnet registry | The harness stakes real Testnet XLM and writes real registry entries; an incomplete run leaves state behind |
